## ✨ Mobilní optimalizace
- **Mobile First navigace**: Spodní navigační lišta (Bottom App Bar) pro snadné ovládání jednou rukou.
- **Rychlý přepínač rolí**: Spodní vysouvací panel (Bottom Sheet) pro přepínání mezi rolemi (PM, Účetní, Obchodní, ERA).
- **Dotykově optimalizované KPI dlaždice**: 2×2 mřížka přizpůsobená displejům telefonů.
- **iOS Safari ochrana**: Velikost vstupních polí 16px zamezuje nežádoucímu automatickému přibližování stránky při psaní.
- **Podpora SafeArea**: Ochrana výřezů displeje (Notch / Dynamic Island) a spodního systémového pruhu.
